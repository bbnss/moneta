# UI review — 8 October 2026

This records the initial local review after 0.2.1, before publication. The approved Cash redesign and these changes are included in 0.2.2; see [0.2.2 verification](VERIFICATION_0.2.2.md).

## Implemented

- The two currency selectors use an equal-width column. The rectangular 64×48 dp swap control is centred on that same column, with symmetric vertical padding: 8 dp on normal screens, 4 dp on compact screens. Both amount fields have a visible surface. The compact calculator has 6 dp vertical gaps, retaining 48 dp buttons and enough room for both fee-adjusted and reference amounts.
- Chart axes and the low/latest/high values use at most two fractional digits, with `k` for thousands and `m` for millions. Tiny rates that would round to zero use scientific notation. These labels do not change calculation precision. Axis spacing is measured from the actual labels and font scale, with space above and below the grid to prevent clipping.
- Board copy includes a localized title, quotation date, verification date/time in the local time zone, base amount, selected conversions in their saved order, and the public Moneta repository link. Missing dates and rates remain explicitly unknown.

## Cash diagnosis and proposed next change

At the time of this initial review, Cash kept an independent `local/home` pair. Its selectors displayed Home first and Local second, while the table showed Local denominations first and Home equivalents second. The columns had no currency headers. Changing Home therefore changes only the right-hand conversion; this reproduces the reported EUR/EGP behaviour.

The original denomination catalog contained 75 currencies. Unknown currencies used a generated 1–2–5 amount series, including in the banknote counter. Even known lists are incomplete or dated: EUR omits the still-valid €500 note, CHF omits 1000 francs, and DKK includes the withdrawn 1000-krone note. The catalog is not a complete, verified inventory of banknotes worldwide.

Next change proposed in this initial review and subsequently implemented in 0.2.2:

1. Replace Home/Local with explicit selectors in table order: **Banknotes: EGP → Value in: EUR**. Repeat the codes in the column headings and counter totals. The first selector changes denominations; the second changes only their conversion.
2. Keep **Table** for seeing each banknote's value and **Count banknotes** for integer quantities and the total. Retain counts by banknote currency and reference-rate conversion without Convert fees. Preserve existing saved pairs and counts.
3. Verify denomination lists against central-bank sources and record their scope/date. Keep illustrative amounts separate from actual banknote lists. Do not present generated amounts as countable real notes; show unavailable catalog coverage clearly and retain any previously saved counts.

Official sources checked for the catalog diagnosis:

- [ECB: current banknotes and the still-valid €500 note](https://www.ecb.europa.eu/euro/banknotes/current/html/index.en.html)
- [SNB: current banknote series, including 1000 francs](https://www.snb.ch/en/the-snb/mandates-goals/cash/series-9)
